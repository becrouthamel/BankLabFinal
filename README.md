<h3>Multithreaded Banking Server</h3>
This is a Java-based banking server application initially developed for the final project of an Advanced Java course. This project is meant to focus on and explore multithreading, concurrency, synchronization, and client-server architecture through a simulated banking environment.

<h4>Functionality</h4>
This multithreaded banking server allows for multiple users to connect to a banking server, create an account, log in, and manage their account and balances concurrently. This application demonstrates a server that can handle simultaneous client interactions while maintaining data consistency and protecting shared account information through synchronization.

<h4>Features</h4>
This application allows for users to create and log in to their banking accounts, letting the users maintain and manage their own balances through client-server interactions. Concurrent processing handles multiple client interactions simultaneously using Java multithreading. This application also utilizes synchronization to protect shared account data and maintain balance consistency during concurrent transactions.

<h4>Technologies Used</h4>
Java, Maven, MySQL, MyBatis

<h4>Concepts</h4>
Multithreading, concurrency, synchronization, shared resource management, client-server architecture, concurrent client interactions, object-oriented programming
